# RETINAL Page

## 추가 페이지 작성 규칙

- 페이지와 섹션 제목 아래 부제목/설명 문단은 기본적으로 작성하지 않는다.
- 사용자가 명시적으로 요청하거나 업무 진행에 꼭 필요한 안내 문구만 예외로 둔다.

## Naming

- 코드 작성 및 수정 시 `.codex/skills/naming/SKILL.md`의 RETINAL 네이밍 규칙을 먼저 따른다.

RETINAL의 실제 화면 단위와 라우팅을 작업할 때 이 스킬을 사용한다.

## 먼저 확인할 파일

- `.codex/design-system.md`
- `src/App.svelte`
- `src/config/path.js`
- `src/config/routes.js`
- `src/router/`
- `src/components/layout/`
- `src/app.css`

## 라우트 등록 규칙

- 페이지 컴포넌트는 `src/router/{domain}/` 아래에 둔다.
- URL 상수는 `src/config/path.js`의 `PATH` 또는 `ROUTE_PATH`에 추가한다.
- 라우트 컴포넌트 import와 등록은 `src/config/routes.js`에서 처리한다.
- 동적 라우트는 파일명에 `[id].svelte`를 사용하고, 라우터 path는 `ROUTE_PATH`에 둔다.
- 기존 `@maks11060/svelte5-router` 기반 구조를 유지한다.

## 페이지 구조

- `/auth/login`: RETINAL 로고, 서비스명, 매장 ID, 직원 ID, 비밀번호, 로그인 버튼, 비밀번호 찾기
- `/dashboard`: 얼굴 분석 진입을 중심으로 한 대시보드 홈
- `/users`: 고객 관리 목록, 검색, 신규 등록 버튼, 고객 목록 카드
- `/users/:id`: 고객 상세, 프로필 요약, 분석 완료 배너, AR 피팅 시작, 액션 카드 그리드
- `/records`: 기록 관리, 기간 필터, 검색, 기록 테이블, 페이지네이션
- `/sales`: 판매 통계, 월 요약, 지표 카드, 매출/주문 차트
- `/branches`: 지점 관리, 지점 카드 그리드

현재 프로젝트에 없는 `/records`, `/sales`, `/branches`를 만들 때는 `path.js`, `routes.js`, 사이드바 메뉴를 함께 갱신한다.

## 페이지 레이아웃 규칙

- 모든 페이지 최상위 `main`에는 `app-frame-page`를 붙인다.
- 전체 화면 기준은 `App.svelte`의 `app-frame-shell`과 1366x1024 `app-frame`이다.
- 로그인 화면은 전체 화면 gradient 배경과 중앙 인증 패널을 사용한다.
- 로그인 이후 화면은 좌측 고정 사이드바와 우측 콘텐츠 영역을 기본으로 한다.
- 대시보드성 페이지는 상단 바, 콘텐츠 컨테이너, 카드/테이블 영역 순서로 구성한다.
- 페이지 제목은 중앙 정렬이 필요한 화면과 좌측 정렬이 필요한 화면을 구분한다.
- 뒤로가기 텍스트는 현재 화면의 진입 맥락에 맞춘다. 예: 고객 목록, 대시보드, 뒤로가기.
- 페이지 전용 mock data는 API 연결 전까지 해당 페이지 파일 또는 근접한 module에 작게 둔다.
- 실제 API 연결 시 `src/lib/api` 책임으로 분리한다.

## 화면별 인터랙션 기준

- 고객 관리: 검색어로 이름/전화번호 필터링, 신규 등록 모달 열기, 고객 상세 이동
- 신규 고객 등록: 이름, 성별, 생년월일, 전화번호, 이메일 입력과 필수 검증
- 고객 상세: AR 피팅 시작, 측정값 입력, 얼굴 분석, 기록 관련 액션 진입
- 기록 관리: 기간 필터 선택, 검색 실행, 페이지 이동
- 판매 통계: 기간 또는 지점 선택이 생기면 상단 우측 컨트롤로 배치
- 지점 관리: 지점 카드 선택 시 상세 또는 관리 액션으로 확장 가능하게 설계

## 완료 전 체크

- 새 페이지가 `PATH`와 `routes`에 모두 등록됐는지 확인한다.
- 사이드바 활성 상태가 현재 route와 일치하는지 확인한다.
- 버튼과 링크의 역할이 섞이지 않았는지 확인한다.
- `npm run build`로 라우트 import와 Svelte 문법 오류를 확인한다.
